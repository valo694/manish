# Manish Kashyap — Portfolio (MK_OS)

Single-file terminal portfolio. No build step, no dependencies.

## Deploy on GitHub Pages (2 minutes)

1. Create a new repository on GitHub (e.g. `portfolio`).
2. Upload these files to the repo:
   - `index.html`
   - `Manish-Kashyap-Resume.pdf`
3. Go to **Settings → Pages**.
4. Under "Build and deployment", set Source = **Deploy from a branch**,
   Branch = **main**, folder = **/ (root)** → Save.
5. Wait ~1 minute. Your site goes live at:
   `https://YOUR-USERNAME.github.io/portfolio/`

## Updating later

Edit `index.html` and push — the site updates automatically.

## Notes

- Everything (styles, scripts, 3D model, terminal) lives inside `index.html`.
- The PDF is linked from the hero "DOWNLOAD CV" button — keep the filename as is,
  or update the `href` inside `index.html` if you rename it.
